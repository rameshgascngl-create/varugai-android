VARUGAI Privacy Policy

Effective date: 25 September 2026
Applies to: VARUGAI 16.0.2, package com.gasczoology.varugai.

Purpose

VARUGAI is an offline attendance register and academic attendance manager intended for authorized faculty or institutional staff.

Data stored on the device

VARUGAI may store institution, department, faculty, course, class, semester and academic-year information; student names, roll numbers and register numbers; attendance marks; calendar and holiday information; notes; and audit records. These records may be personal or academic records and should be handled according to the user's institutional obligations.

Collection and sharing

The current version does not transmit attendance or student records to a developer server. It contains no advertising, analytics, behavioral-tracking, cloud-synchronization or crash-reporting SDK. It does not request Internet, camera, microphone, contacts, location, SMS or phone permissions.

Files leave VARUGAI only when the user explicitly exports, shares or restores files through Android's system file interfaces. CSV, XLSX and PDF exports are not encrypted by VARUGAI after they are handed to the selected destination application. Portable VARUGAI backup files are encrypted.

Security

The local Room database uses SQLCipher. Database key material and PIN verification use Android Keystore-backed cryptographic material. The application blocks screenshots and screen recording through Android's secure-window flag. Portable backups use authenticated encryption and require the VARUGAI recovery key.

Recovery key

The recovery key should be recorded separately from the phone. If both the device-held key and the separately recorded recovery key are lost, encrypted portable backups may be unrecoverable. VARUGAI cannot reconstruct a lost recovery key.

Deletion

A register can be deleted from Setup, which removes its locally stored roster, calendar, attendance and audit history. Uninstalling VARUGAI removes its local application data. Android automatic backup and device-transfer backup are disabled for VARUGAI data.

Permissions

VARUGAI is designed to operate offline and does not request Internet, camera, microphone, contacts, location, SMS, phone, alarm, notification or broad storage permissions.

Contact

Support and privacy questions can be submitted through the public project issue tracker at github.com/rameshgascngl-create/varugai-android/issues.

Changes

If a future version introduces network services, analytics, advertising, synchronization or materially different data handling, this policy and the store Data Safety declaration must be updated before release.
