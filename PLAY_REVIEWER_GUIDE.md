# VARUGAI 16.0.2 — Play reviewer guide

VARUGAI is an offline faculty attendance register. Reviewers do not need institutional credentials or network access.

## Safe review path

1. Install the release candidate.
2. On first launch, create a temporary 4–8 digit PIN solely for review.
3. Create a sample register using fictitious institution/course information.
4. Add only fictitious student records, for example Student 001 / Student 002.
5. Generate a short semester calendar.
6. Mark a few P/A/OD attendance cells and complete a day.
7. Open Summary to verify totals.
8. Open Export and create the recovery key. Record the displayed test key temporarily.
9. Export an encrypted backup, then restore it to the same sample register.
10. Delete the sample register when review is finished.

No real student data, private institutional credentials or preloaded production records are required.
